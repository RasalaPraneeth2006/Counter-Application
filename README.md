# 🔢 Counter Application

A simple and interactive counter application built using **HTML**, **CSS**, **JavaScript**, and **Bootstrap**. The application allows users to increase, decrease, and reset the counter while dynamically changing the counter's color based on its value.

---

## 📌 Features

- ➕ Increase the counter value.
- ➖ Decrease the counter value.
- 🔄 Reset the counter to zero.
- 🎨 Dynamic color changes:
  - 🟢 Green for positive values
  - 🔴 Red for negative values
  - ⚫ Black for zero
- 📱 Simple and responsive user interface.

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (DOM Manipulation)
- Bootstrap 4

## 🚀 How It Works

### ➕ Increase Button
- Increments the counter by **1**.
- Displays the value in **green** when the counter is positive.

### ➖ Decrease Button
- Decrements the counter by **1**.
- Displays the value in **red** when the counter is negative.

### 🔄 Reset Button
- Resets the counter value to **0**.
- Displays the value in **black**.
